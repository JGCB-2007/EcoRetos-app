# 🌿 EcoRetos

### 🌱 Sobre el proyecto

**EcoRetos** es una aplicación móvil enfocada en fomentar hábitos sostenibles mediante retos ecológicos.  
Permite a los usuarios participar en actividades ambientales, ganar puntos y visualizar su progreso de forma interactiva.

El objetivo es incentivar el cambio de comportamiento a través de la gamificación, promoviendo acciones que impacten positivamente el medio ambiente.

---

### 🚀 ¿Qué permite hacer?

- 🌍 Aceptar retos ecológicos  
- ✅ Completar actividades y ganar puntos  
- 📊 Visualizar impacto ambiental personal  
- 🏆 Ranking de usuarios  
- 🎖 Sistema de medallas (gamificación)  
- 👤 Perfil con progreso y estadísticas

### ⚙️ Arquitectura

El proyecto sigue una estructura basada en:
- **UI (Jetpack Compose)** → Interfaces  
- **ViewModel** → Lógica de estado  
- **Retrofit** → Comunicación con API  
- **Backend (Spring Boot)** → Gestión de datos  
- **SQL Server** → Persistencia
